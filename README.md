# pi-rbf

Rigelblu flavor of Pi coding agent extensions and capabilities.

## Extensions

- [`rbf-exit`](extensions/README.md) (v0.2.0) — Use `/exit` to quit Pi cleanly, matching native `/quit` and standard shell muscle memory.
- [`rbf-stash-prompt`](extensions/README.md) (v0.1.0) — Set aside my current prompt in the main editor with `Ctrl+S` and restore or swap it intact.
